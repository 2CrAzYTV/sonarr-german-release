Credits & Datenquellen

Wikidata wird für die exakte Zuordnung vorhandener IMDb-/TheTVDB-IDs verwendet. Strukturierte Wikidata-Daten sind unter CC0 verfügbar.

Wikipedia DE wird ausschließlich über die offizielle MediaWiki Action API gelesen. Übernommen werden nur Tabellenfelder, die ausdrücklich eine deutsche oder deutschsprachige Erstausstrahlung ausweisen.

fernsehserien.de wird mit niedriger Abfragefrequenz für öffentlich sichtbare Episodenguides verwendet. Übernommen werden ausschließlich explizit als deutsche TV-/Streaming-Premieren bezeichnete Termine.

TVmaze wird über die kostenlose öffentliche API für exakte Serien-Mappings und explizite deutsche Country-Premiere-Alternate-Lists verwendet.

This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB bleibt vollständig optional. Streaming-Verfügbarkeitsdaten werden nur bei konfiguriertem TMDB-Token von JustWatch über die TMDB Watch-Provider-Endpunkte bereitgestellt.
